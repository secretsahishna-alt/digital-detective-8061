# Task 3.4 — Explain operating-system responsibilities

| OS Responsibility | Your Explanation | Example |
|---|---|---|
| **Process management** | The OS starts and stops programs and decides which program uses the CPU. | Switching between a browser, code editor, and music player. |
| **Memory management** | The OS gives active programs the RAM they need and frees RAM when a program closes. | A video player uses RAM while open, then releases it after closing. |
| **Device management** | The OS lets programs communicate with hardware through drivers. | A mouse moves the cursor and a printer prints a document. |
| **File management** | The OS stores, organizes, and manages files and folders. | Creating folders, saving a text file, or renaming files in Finder or Terminal. |
| **User interface / shell** | The OS provides a way for people to control the computer using icons or commands. | Using the macOS desktop or typing commands in `zsh`. |
| **Security and permissions** | The OS protects the system and controls who can view or change files and settings. | Using a password or Touch ID to change settings or open restricted files. |
