# Task 3.2 — Understand processes

### 1. What is a process?
A **process** is when a set of instructions saved in the computer main storage is executed in the operating system with an allocated time on CPU.

---

### 2. What does the PID column represent?
**PID** stands for **Process Identifier**. It is an unique number allocated to every process running on the computer by the CPU.

---

### 3. Give two examples of processes that may be running on your computer:
1. **Application (Foreground) Process:**
   - **`Antigravity` / `Visual Studio Code`**: An interactive editor application running with user interface windows, active user input handling, and child helper processes.
2. **Background System Process (Daemon):**
   - **`launchd` (PID 1)**: The primary init and service-management daemon on macOS responsible for launching system services, daemons, and managing background jobs.
   *(Another common example is `WindowServer`, which manages the GUI window rendering and display outputs on macOS).*
