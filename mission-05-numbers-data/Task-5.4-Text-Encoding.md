# Task 5.4 — How is text stored?

## 1. ASCII Decimal Codes for Letters
- **Uppercase letter 'A':** Decimal code **`65`** (Binary: `01000001`, Hex: `0x41`)
- **Lowercase letter 'a':** Decimal code **`97`** (Binary: `01100001`, Hex: `0x61`)

## 2. Why does a computer need an encoding standard to store text?
- Ans: Computers operate entirely on binary electrical states (0s and 1s) and cannot natively understand human letters, symbols, or alphabets. A character encoding standard  standardizes reference system where every character is mapped to a specific numerical code, ensuring that text written on one computer can be stored, transmitted, and displayed identically on any other system without becoming corrupted.

## 3.Name one example of a character that is not part of basic ASCII.
- Ans: Euro currency symbol (`€`): Unicode code point `U+20AC` are not part of ASCII.
