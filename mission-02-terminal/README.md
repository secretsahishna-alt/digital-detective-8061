## 3. Commands / Tools Used

| Command | Purpose |
|---|---|
| `pwd` | Displays the current directory. |
| `ls` | Lists files and folders. |
| `ls -l` | Displays detailed directory information. |
| `cd ..` | Moves to the parent directory. |
| `mkdir` | Creates a directory. |
| `touch` | Creates an empty file. |
| `cp` | Copies files. |
| `mv` | Moves or renames files. |
| `cat` | Displays file contents. |
| `echo` | Prints text or writes text to a file. |
| `>` | Replaces file contents. |
| `>>` | Appends text to a file. |
| `ls -lah` | Displays detailed listings, including hidden files and readable sizes. |
| `head` | Displays the beginning of command output. |
| `brew --version` | Checks the Homebrew version. |
| `brew list` | Lists Homebrew-managed packages. |
