# Task 2.1 — Explore basic Terminal operations
| Operation / Command Name | What It Does | What I Observed |
|---|---|---|
| `pwd` | Displays the path of the current working directory. | It displayed the location of my practice folder.|
| `ls` | Lists files and folders in the current directory. | It displayed the available files and folders. |
|`ls -la` | Displays detailed information such as permissions, file size and modification date with hidden files. | I could see additional information about each file. |
| `cd ..`| Moves to the parent directory. | My current location changed to the folder above my current directory. |
| `mkdir practice`| Creates a new folder named practice. | A new practice folder was created. |
|`touch practice/original.txt` | Creates an empty text file inside the practice folder. | The practice.txt file was created. |
| Copy file (`cp practice/practice.txt practice/practice2.txt`) | Creates a copy of the original file with a different name. | A second file named practice2.txt was created. |
| Move / Rename file (`mv practice/copy.txt practice/practice_new.txt`) | Renames a file into another name.| The copied file was renamed to practice_new.txt.|
| Display file contents (`cat practice/practice_new.txt`) | Displays the contents of a text file. | The contents of the original file appeared in Terminal. |
