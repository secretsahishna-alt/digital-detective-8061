# Task 7.1 — Explain network concepts

| Concept | Explain it in your own words | Example |
|---|---|---|
| **LAN (Local Area Network)** | A network connecting computers and devices in a short distanced geographical area. | College computer lab network. |
| **MAN (Metropolitan Area Network)** | A larger network stretching across a town or sometimes a city |Public Wi-Fi network|
| **WAN (Wide Area Network)** | A very large network that connects devices and networks countries, or the entire globe. | The global Internet |
| **DNS (Domain Name System)** | It translates human-friendly domain names into computer-friendly numerical IP addresses. | Translating `google.com` into its IP address `142.250.190.46`. |
| **Router** | A networking hardware device that directs data traffic between different networks and forwards data packets to their destinations. | Home Wi-Fi router  |
| **Protocol** | An agreed set of standardized rules that govern how data is formatted, transmitted, and received across a network. | HTTP / HTTPS  |
| **Packet switching** | The method of breaking data into small, manageable chunks called packets, sending them  across the network, and reassembling them at the destination. | Streaming a YouTube video where audio and video chunks travel as packets over various routes and play smoothly. |
| **Client-server** | A network architecture where one computer/program (client) requests services or resources, and another computer (server) provides them. | Your browser (client) requesting a web page from a web hosting server (server). |
