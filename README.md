# Digital Detective — Independent Learning Assignment

## About This Project

Welcome to my Digital Detective Independent Learning Assignment!
This repository contains my work as I explore computer fundamentals, operating systems, command-line operations, programming and other important computing concepts.
The purpose of this assignment is to develop practical computer skills through hands-on activities, experiments and documentation.
Each mission focuses on a different topic, with completed tasks, explanations and evidence organised into separate folders.

## How to Run the Number Converter

To run the number converter, first open Terminal and navigate to its mission folder.

```bash
cd mission-03-operating-system
```

Then run the program using the appropriate command for its programming language.
```
python3 number_converter.py
```
