# Task 1.1 — Trace one activity using IPOS

Example: Typing and saving a document.

| Stage | What happens in my example? | Hardware / Component |
|---|---|---|
| Input | I type text using the keyboard and use mouse. | Keyboard and mouse |
| Processing | The CPU processes my keystrokes and RAM temporarily stores the data. | CPU and RAM |
| Output | Monitor gives visual outputs| Monitor |
| Storage | I save the document on my computer and it goes in storage. | SSD / Hard Disk |
