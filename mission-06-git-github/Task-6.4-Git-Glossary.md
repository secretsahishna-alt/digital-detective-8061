# Task 6.4 — Git Command Glossary

Simple one-line explanations for everyday Git operations:

1. **Initialise a repository (`git init`):**
   Initialises git in the file or instructs git to supervise changes.

2. **Check status (`git status`):**
   Shows which file had changed ,untracked files, staged files.

3. **Stage changes (`git add`):**
   Puts file in staging area or instructs git to document the changes of the file.

4. **Commit changes (`git commit`):**
   Saves a permanent snapshot of your staged work with a message describing what you did.

5. **View history (`git log`):**
   Lists all previous commits made in the project so you can trace what happened and when.

6. **Create or list branches (`git branch`):**
   Shows all existing branches or makes a new branch so you can work on features separately.

7. **Switch branches (`git checkout` / `git switch`):**
   Switches to another branch.

8. **Publish changes (`git push`):**
   Uploads your local commits and branches from your computer up to GitHub.

9. **Retrieve remote changes (`git pull`):**
   Downloads the latest updates from GitHub and merges them into your local project.
